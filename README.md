# 贷款还款记账APP
## 功能说明
按照需求开发，完整功能：
1. **三个底部导航栏**：总计、全部账目、设置
2. **总计页面**：
   - 显示所有待还借款总额
   - 显示本月需要还款金额
   - 显示当前结算日设置
3. **全部账目页面**：
   - 列出你添加的所有借款平台
   - 每个借款显示平台名称、还款日、每月还款金额
   - 可单独勾选是否已经还款
   - 提供一键批量标记全部已还款功能
   - 浮动按钮添加新借款
4. **设置页面**：
   - 可自定义设置每月几号开始算作下个月账单
   - 支持 1-31 号任意设置
   - 默认是每月 1 号，即自然月
## 项目特点
- 使用 Room 数据库本地存储，数据存在你手机本地，安全隐私
- 完全自动计算，勾选后数据自动同步到总计页面
- 支持添加多个借款平台，每个平台不同还款日
- Material Design 设计，界面美观流畅
## 如何生成APK
### 方法一：使用 Android Studio（推荐）
1. 打开 Android Studio
2. 选择 `File -> Open`，选择 `loan_tracker_app` 目录
3. Android Studio 会自动同步 Gradle
4. 连接你的 Android 手机，打开开发者调试模式
5. 点击 `Run -> Run 'app'` 就可以安装到手机
6. 或者点击 `Build -> Generate Signed Bundle / APK` 生成正式APK
### 方法二：使用在线构建服务
可以将项目上传到 Github，使用 Github Actions + Android 镜像自动构建出 APK
## 使用方法
1. 打开APP，进入「全部账目」
2. 点击右下角 + 号添加你的每个借款：输入平台名称、还款日、每月还款金额
3. 添加完成后，在列表中勾选已经还过款的项目
4. 切换到「总计」查看总待还和本月待还
5. 如果需要修改结算日期，进入「设置」修改即可
